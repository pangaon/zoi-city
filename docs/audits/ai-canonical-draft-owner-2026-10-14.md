# AI Studio canonical draft journey

A saved successful AI generation can now save one canonical social draft per original generation item and open its latest owner version in Composer. The additive SQL stores only immutable request receipts and item-to-post links; social_posts and the existing social_save_post writer remain canonical. Server source derives text from the authorized saved generation, retains captured business name and campaign/client identity, and creates no audience, schedule, publication, email or external send.

The browser preserves an actor/workspace/generation/item nonce before dispatch. A response that cannot be confirmed offers an explicit retry of the same original payload. A changed campaign after an uncertain save cannot reinterpret that receipt. Current session and write membership are rechecked for every new write and replay. Different nonces for the same item return the same current canonical post, including later owner edits and assets. Deleted posts are reported as removed and are never silently recreated. Composer preserves imported empty channels even when a connected Facebook fixture and Community are available. Private writing samples remain in the private generation record and are excluded from public post metadata.
