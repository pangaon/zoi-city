# Youth guardian enrollment recovery candidate · 2 October 2026

Candidate only: this producer did not install the migration, publish a deployment, create live child records, send messages or collect payment. Lead owns schema preflight, shared entry cache integration, release and production acceptance. Full recovery scope remains open.

The existing guardian program suite is extended rather than duplicated. Staff publishes an owned organization's actual program and terms, assigns current instructors and links actual calendar classes. A guardian creates a private preferred-name record, requests enrollment with age-band checks and explicit authority/consent, receives a staff decision, sees private class attendance, renews changed terms and withdraws. Children do not have accounts or public profiles. Guardian authority remains self-attested. No birth date, child photo or medical data is collected in this flow.

Lost responses no longer require guessing or recreating sensitive forms. Before a write, web/native persist only an account/workspace/request/operation/identifier/version marker. Names, ages, contacts and consent payload stay in memory. A remount checks the server's receipt; an unsaved request can be atomically cancelled, fencing a late write. Exact retry is offered only while its private payload remains in memory. Old nonce-only browser markers also recover saved receipts or fence missing writes. Current account, workspace, session and role are rechecked before dispatch, after asynchronous refresh/results and after database lock waits. Auth UUID and internal guardian profile UUID are deliberately distinct.

New writes/recovery require a strict numeric installed capability bound to current account and private scope. Older/missing/malformed capabilities remain readable where existing authority allows, with writes and recovery disabled and unresolved markers retained. Wrong identity clears private presentation. There is no fallback to an older writer when recovery capability is absent.

The migration retains old RPC signatures/records through private retained functions, with executable grants revoked from public/anon/authenticated. Public wrappers serialize each actor's writes and cancellation, enforce exact identifier scope, current authority and post-wait session validity, and return checked receipts. Historical receipt lookup does not repeat a withdrawn enrollment. A reviewer found three-valued NULL role logic in attendance authorization; both guards now coalesce missing roles to refusal. Removed-member attendance receipt/cancellation rejection is explicitly tested. The migration pins original writer/reader source hashes and fails on mismatch; parent must also preflight current authority helpers, schema and existing installed migration state.

The Groups wrapper now owns its nested lifetime and destroys detached/replaced private children, including an import arriving after account/workspace change. The shared private-scope helper is used by adult Groups and Youth; this blast radius is covered by composed Groups and retained helper tests. Lead must update Social/Groups entry cache versions consistently before shipping. No Social entry file was edited by this producer.
