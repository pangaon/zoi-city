## Correction and semantics

The new function reads only public eligible country/region/city once, grouping identical raw place tuples and preserving their listing count. It canonicalizes each distinct raw country once and merges aliases by summing counts. Final distinct region/city counts retain the prior exact text/null behavior across aliases. Empty country and canonical-null country behavior, published/clean-or-cleared/not-hidden checks, output bigint types and descending-count/name ordering are unchanged. No deduplication of listing identities is introduced: the prior function counts eligible records, including repeated records at the same place.

No new table, persistent cache, grants, index, owner mutation or timeout increase. Security-definer and empty search_path match the current intentional public aggregate contract.
