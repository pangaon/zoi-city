The service consumer processes four current `official_sources_v1` leases per invocation. It captures the registered website and at most two scoped contact/location pages, obeys robots and host spacing, checks public DNS, caps bytes and time, and persists results through the existing lease/input CAS gate. It never applies geography, publishes a home, invokes a geocoder, or marks an empty batch complete.

Deployment prerequisites are an internal `GEOGRAPHY_REPAIR_TOKEN` of at least 32 characters, `GEOGRAPHY_REPAIR_PRIVATE_BUCKET` naming a private Storage bucket, and the explicit `GEOGRAPHY_REPAIR_SOURCE_ENABLED=on` switch. The consumer checks bucket privacy and calls service-only `geography_source_archive_budget()` before leasing. Exhausted, malformed or missing budget blocks the invocation with `complete:false`. The reply must allow a 15,000,000-byte invocation reserve within a global limit no greater than 512 MiB across current Storage objects. Source bodies are archived by decoded UTF-8 SHA256 before queue finish. Authentication uses `x-geography-repair-token`; the scheduler must also satisfy the deployed gateway JWT configuration. No credentials belong in source or audit artifacts.

Root must review and deploy the function, provision the private archive and internal token, and register a server-side recurring invocation using pg_cron/pg_net and Vault references or the existing authorized scheduling mechanism. A two-minute interval with one bounded invocation is the initial proposed rate. Production canary acceptance must show actual Edge DNS-pinned HTTPS compatibility, private archive retrieval/hash agreement, finish readback, and zero listing coordinate writes before scheduling begins. Local Deno compatibility alone does not prove the hosted runtime.

The generated Edge support modules are rebuilt by `node scripts/geography/build-edge-source-consumer.mjs`; reviewed source extractor and transport changes must regenerate these files. The generated extractor has an exact parity regression. Local Node tests exercise unauthorized/public-bucket/empty-batch boundaries; local Deno checks type compatibility and one actual official contact fetch. The full eligible population is already seeded. Job processing is source research, separate from independently reviewed and actually applied street-address results.

The authenticated CI caller can verify a retained private source without retrieving HTML or a service key by posting `{"verify_archive":"<64 lowercase hex SHA256>"}` to the same consumer. The body is capped at 1 KiB. After private-bucket verification, this action reads only the fixed bucket/hash object, caps response bytes at 2 MiB, verifies SHA256, and returns proof metadata only. It performs no budget query, lease, crawl or coordinate write. An empty body or `{}` retains normal processing. Decoded archive upload bytes are capped at 2 MiB per page and 15,000,000 bytes per invocation.

Normal captures additionally acquire the service-only singleton lease via `geography_source_capture_acquire(p_lease uuid)` before budget or queue leasing, and release only the same UUID in finally. A busy lane makes no budget/queue request. The database lease lasts 180 seconds; worker I/O uses a 110-second invocation deadline with five seconds reserved for cleanup. All concurrent source workers settle before cleanup releases the lease, including failure paths. Private archive verification bypasses this capture lease because it is read-only.
