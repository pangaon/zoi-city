# Website imagery extraction evidence — 30 September 2026

Three existing listings were checked against their recorded official website, with one bounded homepage request each. These are observations of website source HTML, not proof of social-account ownership, a connected social feed, or image availability forever. No listing was changed during this audit. Exact listing IDs, URLs, checked timestamps and extracted source evidence accompany this note in `website-imagery-evidence-2026-09-30.json`.

- **Altes Landhaus Oniro, Essen:** the recorded gallery had three resized/format variants of the same building image. Its actual homepage also contains three background photos omitted by the old extractor. The replacement finds four distinct source images, separates the logo, and finds explicit gallery/contact links. [Official website](https://grieche-essen.de/).
- **Restaurant Aphrodite, Essen:** no recorded gallery/hero. The actual site uses CSS background images, which the old img-only parser missed. Two source image URLs were found alongside actual Facebook/Instagram profile anchors. The CDN URLs include an expiry signature; they must not be described as permanently archived images. [Official website](https://www.aphrodite-essen.de/).
- **Restaurant Pandosia, Essen:** the recorded hero was `pandosia-logo-1920w.jpg`. The replacement classifies that as branding and chooses a separately sourced restaurant image. Known Pexels stock URLs are excluded from the proposed gallery. [Official website](https://www.pandosia-essen.de/).

The worker change separates source logos from photos, resolves relative JSON-LD images, deduplicates resize variants, recognizes background images and filters interface artwork. It may fetch at most two explicitly linked same-origin contact/gallery pages, with the existing robots, DNS, redirects, streaming byte cap, per-host spacing and total invocation budget. It never guesses a website for listings that lack one. It preserves owner fields and replaces only machine enrichment imagery after a successful crawl. Aggregator branding is explicitly cleared from that machine namespace.

Deployment remains required. A production refresh should use the existing leased queue with a small initial batch, verify actual apply receipts and inspect rendered results before increasing cadence. A full-catalog freshness claim would be false after a three-site audit. Signed CDN images and sites requiring JavaScript remain limitations; no private social metrics or feeds are inferred from extracted profile links.
