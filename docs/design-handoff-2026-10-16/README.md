# Zoi — Aegean Glass handoff

Open `index.html` in a browser for the visual guide and full specification.

For Codex, supply this entire folder, then paste `CODEX-START.md`.

Included:
- Full product design and implementation specification.
- 153 identified screen/opening acceptance items in a CSV checklist.
- Fifteen original-resolution concept images: six detailed studies and nine multi-screen boards, depicting 39 screen concepts.
- Exact existing approved glossy Zoi logo master.
- Semantic design tokens in JSON.
- A code-rendered 3840×2160 component/launch sheet and its editable SVG source.
- Asset manifest recording real image dimensions and provenance.

The concepts are design direction. They are not live app screenshots or production-approved business facts. Generated concept dimensions vary; they are preserved without fake upscaling. The component sheet is a genuine 2× direct render of vector-authored controls and text. Use actual rendered app screens for final 3× UI exports.

Status: design handoff only. No Zoi production code or deployment was changed by creating this package.
