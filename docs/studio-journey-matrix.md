# Shared Studio journey matrix

The [machine-readable matrix](studio-journey-matrix.json) covers16 sector templates,
5 shared Studio journeys and25 common acceptance cases. It is a planning/gap map,
not a claim that every journey or listing has been delivered or tested.

Each sector names the owner task, customer outcome, necessary data and permissions,
provider setup, sector-specific failures and current source pointers. Source files
are evidence that a foundation exists—not evidence of production acceptance.

The next shared Studio layer should connect: a filterable template gallery; editable
source-backed content and layout; optional configured speech → transcript review;
brand-voice campaign variants; live/floatable preview; explicit save/publish approval;
and actual per-channel receipts. Existing private recipe Studio is one candidate
vertical, not the finished universal platform. Its public publication, native and
commerce gaps remain explicit.

Every acceptance report must distinguish source facts, rendered output and exercised
customer/owner actions, with actor/workspace boundaries, immutable retry receipts,
mobile/keyboard checks, exact release version and an independent reviewer. The full
platform scope remains in `docs/recovery-scope.json`; this matrix does not replace it.
