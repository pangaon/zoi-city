# Zoi Product Map

## Canonical live tools

| Product | URL | Use it for |
|---|---|---|
| Zoi Business | `/social` | Compose, schedule, templates, analytics, audience, email, accounts, business page |
| Zoi Tickets | `/tickets` | Create events, free reservations, QR tickets, attendees, Door mode |
| Founder Command Center | `/apps/command-center/` | Directory operations, claims, reviews, ingestion, enrichment and system pulse |
| Zoi Directory | `/explore` | Search and claim listings |
| Zoi Map | `/explore/map` | Browse listings geographically |
| Zoi Community | `/community` | Community feed and discussions |
| Apps hub | `/apps/` | Launch the products and understand live versus preview |

## Preview surfaces retained for merge work

These files are not deleted. They are preserved as source material and design
research until their useful capabilities are merged into canonical products:

- `/apps/business-pro/`: sample operator/social concept. Use `/social` for live work.
- `/apps/event-os/`: floor-plan and event-operations concept. Use `/tickets` for durable event records.
- `/apps/tickets-studio/`: seat-map and 3D concept. Use `/tickets` for live reservations.
- `/apps/intelligence/`: SEO/GEO/AI-citation concept. Founder visibility currently lives in Command Center.
- `/explore/app/`: quarantined legacy prototype. Use `/explore` for the canonical directory.

## Navigation rule

The global header now includes **Apps**. The Social sidebar links to the live
Founder Command Center and labels Business Pro as a preview. No preview surface
is treated as a live source of truth until its data and actions are connected to
the canonical backend.
