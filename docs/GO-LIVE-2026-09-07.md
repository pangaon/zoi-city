# Zoi go-live release candidate — 2026-09-07

## Release scope

This release stabilizes the existing public product. It does not activate paid
tickets, external social publishing, email sending, or prototype Apps.

## Verified production blockers addressed

1. Directory search returns HTTP 300 because production contains two defaulted
   `explore_search` overloads. Migration 0019 removes the stray eight-argument
   overload and restores the canonical seven-argument contract.
2. Community feed returns HTTP 300 because production contains two defaulted
   `feed_list` overloads. Migration 0020 removes the stray scoped overload.
3. Raw database errors were printed in the public directory and community UI.
   Both surfaces now show a stable retry state while retaining diagnostic detail
   in the browser console.
4. The shared mobile header could overflow and obscure navigation. Navigation
   now owns the remaining width and the secondary CTA is removed at phone sizes.
5. Cross-realm Date objects produced wrong fasting guidance in the browser
   liturgical calendar. Date handling is now realm-safe and UTC-normalized.
6. Vercel now applies baseline MIME-sniffing, clickjacking, referrer, camera,
   microphone, geolocation, and payment restrictions.

## Required deployment order

1. Apply migrations 0019 and 0020 to Supabase as one reviewed database phase.
2. Re-run the production contract suite; require 24/24 passing.
3. Require local/unit, inline-JavaScript, HTML, and API syntax checks to pass.
4. Deploy the exact reviewed Git commit to a Vercel preview.
5. Verify `/`, `/explore`, `/community`, `/social`, `/tickets`, `/explore/map`,
   `/in`, a real listing, and all sitemap endpoints on mobile and desktop.
6. Promote that same preview artifact to production.
7. Repeat search/feed/header/header-security smoke checks on `www.zoi.city`.

## Rollback

- Frontend: Vercel Instant Rollback to the previous deployment.
- Database: do not recreate ambiguous overloads. If a regression appears,
  restore the canonical function body with a compensating migration.

## Deliberately not activated

- `payments_live`
- `feature_email`
- `feature_social_publish`
- unlabelled prototype/Labs functionality

These remain off until their own end-to-end release gates pass.
