# Properties — candidate

Distinct sale, long-term rent and holiday-stay offers; no inventory generated from realtor/villa search matches. A host is an owned public agent/business/property home. An optional place_id identifies a separate owned public physical property home and enables saving a planned visit to a private trip. Ownership of the platform home is enforced; representation as property owner/authorized agent is an explicit author attestation, not an independently verified legal title or licence.

Prices always have their basis: sale asking price, monthly rent, nightly holiday rate. Price-on-request is explicit. Additional fee terms are visible; this is an advertised quote, not checkout or confirmed accommodation availability. Agent-supplied source URL and review date are shown. Missing required facts cannot be published. Marking a source conflict automatically pauses publication; conflict reason and private audit stay with owner/admin.

Owner/admin save offers; normal private enquiry inbox remains owner/admin/editor. Customer requests are authenticated, private, stable-ID and keep an immutable offer snapshot. A viewing/stay date request is NOT confirmation. A link to available agent appointments is shown only if the existing host booking system is configured; it does not prove property accommodation availability. No payment, external notifications or scraping assertions.

- `property_operator(p_workspace uuid)` → `{ok,owned,offers,audit,requests}` owned public supported homes `{id,name,entity_type}`, all private offer rows max200, latest100 audit and latest100 private requests with original snapshots.
- `property_offer_save(p_workspace uuid,p_id uuid,p_expected_version integer,p_data jsonb)` → `{ok,offer}`. New stableUUID expected0/exact initial retry; optimistic edits. Data fields: `host_id`, optional `place_id`, `mode` sale/long_rent/holiday_stay, `timezone` valid IANA property timezone, `title`1..180, `description`<=5000, `city`1..120, `country`1..120, `public_address`<=300 (optional, explicitly public), `price_on_request`boolean, `price_cents` integer/null, `currency`uppercase3, `area`number/null, `area_unit`sqm/sqft/null, `bedrooms`integer/null, `photos`HTTPS URLarray<=12, `fee_terms`<=2000, `source_url`HTTPS<=2000, `source_checked_on`YYYY-MM-DD not future, `representation`owner/authorized_agent, `representation_confirmed`true, `status`available/under_offer/sold/let/unavailable, `published`boolean, `source_conflict`boolean, `conflict_reason`<=2000 required if conflict. Save validation requires complete basic fields; publication additionally requires source/representation/fee_terms acknowledgement. Price basis derived server from mode; invalid mode/status pairing rejected.
- `property_catalog(p_host uuid|null=null,p_offer uuid|null=null,p_mode text|null=null,p_city text='')` → `{ok,offers}` at most50 currently public offers. Each public offer `{id,host_id,place_id,version,data,status,updated_at,agent_name,agent_slug,place_name,place_slug,booking_url,offer_url}`. `data` normalized public facts only; private source conflict text/initial raw payload/audit/actor absent. Booking link only current owned enabled booking settings.
- `property_request(p_offer uuid,p_expected_version integer,p_request uuid,p_data jsonb)` → `{ok,request}`. `{kind:'information'|'viewing'|'stay',message:1..3000,preferred_start:null|explicitISO,preferred_end:null|explicitISO,timezone:null|IANA}`. Information can omit dates; viewing/stay require explicit valid interval <=90days in the advertised property timezone; stay only holiday offers. Actual current published available offer/version required; max10new/profile/day. Immutable snapshot of normalized original offer facts + offered status/price; creates existing private inquiry thread atomically. Request row `{id,offer_id,profile_id,request_id,initial_data,data,offer_snapshot,inquiry_id,created_at}`. Never a booking/approval receipt.
- `property_requests_mine()` → `{ok,requests}` latest50 own snapshots and thread links, no unrelated customers or agent private data.

Actual private trip linkage: customer may select an existing own trip and save a planned visit via existing trip_item_save using verified public offer.place_id, explicit chosen timezone/start/end and private note with offer title/directURL. No place_id means no location inference from agent's city. Property website images are only supplied by authorised editor; no synthetic stock images presented as the property.
